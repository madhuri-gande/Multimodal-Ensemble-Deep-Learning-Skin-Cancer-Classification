
# Multimodal Skin Cancer Prediction App

## How to Run

1. Place your models in the `models/` folder.
2. Run the app using:

```bash
streamlit run app.py
```

## Upload Instructions

- Upload a skin lesion image (.jpg/.png)
- Upload a single-row CSV containing 26 metadata features

The app will process both inputs and make a prediction using the stacked model.
